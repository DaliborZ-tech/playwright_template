# 05 · Jak bezpečně najít prvek

DOM je strom prvků, ze kterých browser skládá stránku. HTML element může být
například tlačítko, pole nebo řádek tabulky. Role popisuje jeho účel: button,
textbox, heading, row. Accessible name je jméno, které prvek poskytuje
asistenčním nástrojům; často odpovídá viditelnému popisku. U tlačítek Upravit
je v našem portálu doplněné i jméno konkrétního požadavku.

Pole vybírejte přes label: `page.get_by_label("E-mail", exact=True)`.
Tlačítko přes roli a jméno: `page.get_by_role("button", name="Přihlásit se")`.
`page.get_by_test_id("record-row")` vybírá všechny datové řádky podle
domluveného technického identifikátoru. Test ID je vhodný kontrakt, pokud
uživatelská sémantika nestačí. Není to heslo ani interní ID databáze.

Pokud lokátor pro kliknutí najde více prvků, nastane strict mode violation.
To chrání test před kliknutím na náhodný cíl. Nespravujte vše pomocí `first`.
Nejprve omezte oblast: `page.get_by_role("row").filter(has_text="Kontrola přihlášení")`
a uvnitř řádku hledejte konkrétní tlačítko. `to_have_count` naopak s více
prvky vědomě pracuje.

CSS selektor jako `body` se hodí pro obecnou kontrolu dostupnosti. Dlouhá
cesta přes pořadí divů nebo XPath snadno přestane odpovídat po změně layoutu.
Inspector a Pick Locator pomohou zjistit skutečné role a jména. V Codegenu
nejprve vypněte nahrávání, vyberte Pick Locator a ukažte na prvek.

**Úkol 05:** Najděte lokátor hesla a přihlašovacího tlačítka. Po přihlášení
ověřte, že existují tři datové řádky. Řešení je v
`training/solutions/test_05_locators.py`. Vysvětlete, proč počet všech rolí
row není tři: tabulka má také hlavičkový řádek.
