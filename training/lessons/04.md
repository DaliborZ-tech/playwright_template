# 04 · První vlastní Playwright test

Vytvořte `tests/examples/test_my_login.py`. Název souboru i funkce začíná
`test_`, aby je pytest při sběru našel. Napište tento skutečně spustitelný test:

```python
from playwright.sync_api import Page, expect


def test_my_login(page: Page) -> None:
    page.goto("/login")
    expect(page.get_by_role("heading", name="Přihlášení", exact=True)).to_be_visible()
```

První řádek importuje typ stránky a ověřovací nástroj. Parametr `page`
požádá pytest o připravenou kartu browseru. Tomuto mechanismu říkáme fixture;
zatím potřebujete vědět hlavně to, že ji nemusíte vytvářet ručně.
`goto` přejde na cestu v automaticky spuštěném demu. Základ URL dodává
konfigurace fixture, proto nezapisujeme port 5000 do testu.

`get_by_role` popíše hledaný prvek jako nadpis se jménem Přihlášení.
`exact=True` požaduje úplnou shodu jména. Výsledek je Locator, tedy popis
cíle. `expect(...).to_be_visible()` opakovaně kontroluje viditelnost do
limitu; neporovnává jen jediný okamžik. Pokud nadpis nepřijde, test selže.

Spusťte `.\.venv\Scripts\python.exe -m pytest tests/examples/test_my_login.py -v`.
V reportu uvidíte název souboru, funkce a parametr browseru. Máte-li zelený
výsledek, změňte očekávaný nadpis na chybný a sledujte rozdíl. Pak změnu vraťte.
