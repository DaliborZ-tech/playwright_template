# 02 · Instalace a první spuštění

Postupujte podle [instalačního průvodce](../../docs/INSTALL_WINDOWS.md).
Terminál je způsob, jak programu předat přesný příkaz a vidět odpověď.
Začněte kontrolou Pythonu. `py -3.12 --version` nevytváří test; pouze zjistí,
zda je požadovaný interpreter dostupný. Pokud není, další instalaci zatím
nepovažujte za úspěšnou.

Instalační spouštěč vytvoří `.venv`, tedy samostatné prostředí tohoto projektu.
Balíček je sada cizího kódu, kterou používáme. `requirements.lock` zaznamenává
konkrétní ověřené verze všech potřebných balíčků. Balíčky a browser jsou dvě
odlišné instalace: přítomnost Playwrightu ještě neznamená přítomnost Chromia.

Otevřete ve VS Code kořen projektu. Vyberte projektový Python v nabídce
Python: Select Interpreter. Terminál otevřený dříve může stále ukazovat jiný
Python; proto v kurzu píšeme přímo `.\.venv\Scripts\python.exe`.
Nemusíte aktivovat prostředí ani měnit ExecutionPolicy.

Spusťte `scripts\run_smoke.cmd`. Zelený výsledek nyní znamená, že aplikaci
lze otevřít a přihlášení funguje. `scripts\run_visible.cmd` provede stejnou
rychlou kontrolu s viditelným prohlížečem. Parametr slowmo pouze zpomaluje
ukázku pro člověka, neslouží jako čekání na připravenost aplikace.

**Úkol 02:** Spusťte řešení `training/solutions/test_02_login.py` jako jeden
konkrétní test, potom otevřete HTML report a najděte jeho název. Zapište verzi
Pythonu a prohlížeč, ve kterém běžel. Pokud chybí browser, opravou je instalace
`python -m playwright install chromium` z projektové `.venv`, ne přepis testu.
