# 03 · Python, který potřebuje tester

Proměnná je jméno pro hodnotu: `title = "Kontrola exportu"`. Uvozovky tvoří
řetězec, tedy text. Číslo `3` a text `"3"` jsou různé typy hodnot. Seznam
`["Jana", "Petr"]` drží více položek; slovník `{"status": "Nový"}` spojuje
jména s hodnotami. Testovací data tak nemusíte opisovat v každém kroku.

Funkce je pojmenovaný postup. `def test_login_page(page: Page) -> None:`
definuje funkci, kterou pytest spustí. `page` je parametr: místo, kam pytest
předá připravený objekt stránky. `: Page` pomáhá editoru, `-> None` říká, že
funkce nevrací výsledek k dalšímu zpracování. O úspěchu testu rozhodují ověření.

Objekt má data i schopnosti. Objekt stránky umí například `goto`; tomu říkáme
metoda. Tečka v `page.goto("/login")` znamená zavolání schopnosti konkrétní
stránky. `from playwright.sync_api import Page, expect` zpřístupní jména z
knihovny. Import sám neotevírá browser a neprovádí přihlášení.

Čtyři mezery určují tělo funkce. Míchat tabulátory a mezery vede k chybě
odsazení. Podmínka `if status == "Nový":` provede odsazené řádky jen při
splnění porovnání. `=` přiřazuje hodnotu, `==` porovnává. V UI testech však
nepište podmínku, která při chybě aplikace přeskočí assertion; závada má test
zastavit, nikoliv tiše vynechat kontrolu.

**Úkol 03:** V kopii `training/solutions/test_03_python.py` změňte seznam
záznamů na jiné dva syntetické názvy. Vysvětlete parametr funkce `normalize`
a její návratovou hodnotu. Spusťte soubor. Potom schválně odsaďte jeden řádek
špatně, přečtěte chybu a vraťte odsazení. Řešení obsahuje komentovaný příklad
funkce a podmínky; není potřeba browser, protože zde ověřujeme práci s daty.
