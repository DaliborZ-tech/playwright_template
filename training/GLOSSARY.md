# Slovník pojmů

| Pojem | Jednoduché vysvětlení |
|---|---|
| Python / interpreter | Jazyk a program, který provádí jeho příkazy |
| Terminál / CLI | Okno a způsob ovládání pomocí textových příkazů |
| Virtuální prostředí | Složka s vlastním Pythonem a balíčky jednoho projektu |
| Balíček / závislost | Kód dodaný knihovnou, který náš projekt používá |
| Lock | Přesně zaznamenané verze přímých i nepřímých závislostí |
| Import | Zpřístupnění jména z jiného modulu |
| Modul | Python soubor, ze kterého lze importovat kód |
| Funkce | Pojmenovaný postup, který lze zavolat |
| Parametr / argument | Jméno vstupu funkce / konkrétní předaná hodnota |
| Objekt / metoda | Hodnota s daty a schopnostmi / její pojmenovaná schopnost |
| Řetězec | Textová hodnota v uvozovkách |
| Fixture | Příprava a úklid, které pytest předává testu podle jména |
| Scope | Doba sdílení fixture: například jeden test nebo celý běh |
| Browser | Běžící proces prohlížeče |
| BrowserContext | Oddělená browser relace s vlastními cookies a storage |
| Page | Jedna karta uvnitř browser contextu |
| Locator | Opakovaně vyhodnocovaný popis cílového prvku nebo prvků |
| DOM / element | Strom vykreslované stránky / jeden jeho prvek |
| Role | Sémantický účel prvku, například button nebo heading |
| Accessible name | Přístupné jméno prvku pro asistivní nástroje i lokátory |
| Label | Popisek propojený s formulářovým polem |
| Test ID | Domluvený stabilní identifikátor pro automatizaci |
| Assertion | Ověření, zda skutečnost splňuje očekávaný výsledek |
| Auto-waiting | Automatické čekání Playwrightu na připravenost akce |
| Web-first assertion | Ověření UI, které se opakuje do splnění nebo timeoutu |
| Timeout | Nejdelší povolená doba čekání na konkrétní podmínku |
| Strict mode | Ochrana proti akci na nejednoznačném lokátoru |
| Marker | Štítek testu pro výběr, například smoke |
| Parametrizace | Stejný postup spuštěný samostatně s více vstupními daty |
| Regrese / smoke | Opakovaná širší kontrola / rychlá kontrola základního provozu |
| Headed / headless | Browser s viditelným oknem / bez zobrazeného okna |
| Trace / screenshot | Záznam kroků a DOM / obrázek jednoho okamžiku |
| HTML / JUnit report | Výsledek pro člověka / strojově čitelný XML výsledek |
| API / HTTP status | Rozhraní serveru / číselný výsledek požadavku |
| Session / cookie | Stav uživatelské relace / browser údaj předávaný serveru |
| CSRF | Cizí stránkou podstrčená měnící akce; token pomáhá ověřit její původ |
| Base URL | Společný začátek adres aplikace |
| Page Object | Objekt sdružující opakované lokátory a akce stránky |
| CI | Automatické spouštění kontrol po změně zdrojového kódu |
| TTS | Převod psaného textu na syntetický hlas |
| SRT / VTT | Textové formáty titulků s časovými intervaly |
