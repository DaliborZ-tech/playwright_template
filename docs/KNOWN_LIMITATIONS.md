# Známá omezení

Ověřený běhový profil je Windows 11 x64, Python 3.12.15 a Chromium z přesného
locku. Instalace nové `.venv` proběhla na existující stanici. Čistý nově
nainstalovaný Windows, firemní proxy ani všechny alternativní prohlížeče nebyly
samostatně akceptovány. Firefox a WebKit nejsou výchozí ověřený profil.

Skutečný začátečník nebyl k dispozici. Dodaný akceptační scénář a automatizovaný
walkthrough nejsou lidský uživatelský test. Nezávislou technickou revizi provádí
druhý AI reviewer; nejde o lidskou pedagogickou recenzi.

Komentář používá syntetickou Vlastu. Vlastník schválil hlas a krátkou opravenou
ukázku. Anglické odborné pojmy jsou přiblížené českým fonetickým přepisem;
intonace a některá slova mohou působit uměle. QA se vyslovuje „kjů ej“.
Přepis a titulky zachovávají původní pravopis. Úplné lidské poslechové schválení
celého kurzu se bez skutečného poslechu netvrdí.

Produkční Edge TTS integrace je komunitní přístup k online službě. Naměřený
úspěch neznamená garantovanou dostupnost ani neomezené používání. Dodané audio
umožňuje opravu střihu bez nové syntézy. Neodesílejte do něj firemní tajemství.

Demo aplikace uchovává syntetická data jen v paměti a poslouchá na loopbacku.
Slouží k výuce; není to produkční systém ani náhrada firemního přihlášení.
Oddělený externí profil obsahuje pouze schválenou kontrolu dostupnosti přes GET.
Skutečná firemní aplikace nebyla během realizace kontaktována.

Natáčení potřebuje interaktivní plochu. Přepnutí cizího okna do popředí může
záběr zakrýt, proto se kontrolují skutečně extrahované snímky. Reporty a trace
firemních aplikací mohou obsahovat citlivá data a potřebují vlastní retenci.
V distribuci jsou pouze syntetická výuková data; hostname JUnit se při přípravě
veřejných důkazů odstraní s uvedením této redakce.
